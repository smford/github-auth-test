How the auth works

This demo uses the OAuth 2.0 Authorization Code flow. Your browser redirects to GitHub's consent screen, GitHub redirects back with a short-lived code, a Cloudflare Worker securely exchanges it for an access token (keeping the OAuth client secret off the client), and the token is stored in sessionStorage for the tab's lifetime.

The token is validated against api.github.com/user on every page load — if it has expired or been revoked, you are immediately sent back to the login flow.
