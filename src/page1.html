What is GitHub Pages?

GitHub Pages is a static site hosting service that takes HTML, CSS, and JavaScript files directly from a repository on GitHub and publishes a website.

It supports custom domains, HTTPS by default, and integrates natively with GitHub Actions for automated deployments — making it an excellent choice for documentation, portfolio sites, and demos like this one.

How this demo is deployed

Every push to the main branch triggers a GitHub Actions workflow that uploads the src/ directory as a Pages artifact and then calls the Deploy Pages action. The whole process typically takes under 60 seconds. CI/CD
